# Accessible To-Do App

## About

The Accessible To-Do App is a simple web application designed to help users create, manage, complete, and delete tasks.

The project focuses on accessibility and provides meaningful labels for interactive elements so that users can navigate the application using a keyboard and screen reader.

## Features

* Add new tasks
* Mark tasks as complete
* Delete tasks
* Keyboard navigation
* Screen reader-friendly labels
* Accessible buttons and checkboxes
* Simple and user-friendly interface

## Technologies Used

* HTML
* CSS
* JavaScript

## Accessibility Testing

The application was tested using the NVDA screen reader.

NVDA can announce important controls such as:

* Task name
* Add Task button
* Task checkbox
* Delete task button

Example:

> Mark Complete MCA assignment as incomplete

> Delete task Complete MCA assignment, button

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start adding and managing tasks.

## Project Purpose

The purpose of this project is to demonstrate the development of a simple accessible web application with keyboard and screen reader support.
